# 即時新聞

此專案從 Google News 台灣繁體中文 RSS 來源取得最新新聞，並在 App 中呈現焦點新聞、最新新聞列表、搜尋與新聞詳情。

## 功能特色

- 抓取繁體中文即時新聞
- 顯示新聞標題、摘要、來源與發布時間
- 提供關鍵字搜尋，可搜尋標題、摘要與新聞來源
- 點選新聞可查看詳細內容
- 可從新聞詳情開啟原文連結
- 支援重新整理新聞資料

## 資料來源

新聞資料來源為 Google News RSS

## 技術架構

- Kotlin
- Jetpack Compose
- Material 3
- Retrofit
- Android XML Pull Parser
- Coroutines
